# 24. Important distinction about Containerlab and OVS

I previously asked how Containerlab knows about `sw1`.

The important understanding is:

```text
sw1:
  kind: ovs-bridge
```

doesn't mean Containerlab creates a normal Docker container called sw1.

Instead, it represents an OVS bridge on the host.

We created host bridges with:

```bash
sudo ovs-vsctl add-br sw1
sudo ovs-vsctl add-br sw2
```

Containerlab then uses the topology definition to connect container interfaces to those OVS bridges.

This distinction should be maintained in future explanations.
